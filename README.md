# Local Library Reader

Локальное desktop-приложение для хранения и чтения PDF: полки, теги, закладки, заметки, перевод областей и страниц, словарь.

Приложение работает на этом компьютере. Облачных сервисов, аккаунтов и синхронизации нет.

Установщики Windows и macOS Apple Silicon, portable ZIP и автоматические сборки описаны в [DISTRIBUTION.md](DISTRIBUTION.md).
Готовая поставка включает собственный Python. Модели скачиваются через кнопку «Модели»; после загрузки OCR и перевод работают без сети.

Как устроены экраны, каталоги и путь запроса от кнопки до базы — в [OVERVIEW.md](OVERVIEW.md).

## Стек

- React, TypeScript, Vite
- Tauri 2
- PDF.js в читалке
- SQLite
- Python worker: PyMuPDF, PaddleOCR, локальный переводчик

React рисует интерфейс и вызывает команды Tauri. Tauri хранит файлы и SQLite и запускает Python. Python только читает PDF, распознаёт текст и переводит.

## Возможности

Библиотека:

- импорт PDF через системный диалог, копия сохраняется в библиотеке;
- карточки документов, поиск и фильтр;
- виртуальные полки и теги, перетаскивание между полками не двигает файл;
- экспорт копии PDF в выбранную папку;
- корзина, восстановление и отдельное окончательное удаление.

Читалка:

- миниатюры слева, страница по центру, панель справа;
- переход по страницам, масштаб, по ширине и по странице;
- выделение текста мышью и копирование через Ctrl+C на страницах с текстовым слоем;
- поиск по всей книге через Ctrl+F: список результатов, подсветка, переход Enter / Shift+Enter;
- встроенное оглавление PDF с переходом к разделам;
- запоминание последней страницы и масштаба;
- выделение области;
- закладки и заметки документа или страницы;
- переводы области и страницы;
- карточки перевода поверх страницы: показ, перетаскивание, размер, сохранённая позиция;
- словарь книги и общий словарь.

Перевод:

- если у страницы есть текстовый слой, перевод страницы берёт его блоки и координаты;
- если слоя нет, страница распознаётся через OCR, каждая строка становится отдельной областью;
- выделенная область распознаётся через OCR, текст можно поправить до перевода и до сохранения;
- перевод сохраняется в SQLite как TranslationBlock и TranslationVersion;
- повторное открытие страницы не запускает модель;
- повторный перевод страницы пропускает уже сохранённые области;
- «Перевести заново» добавляет новую версию и не удаляет старые;
- активную версию можно выбрать вручную.

Фоновый перевод:

- кнопка перевода добавляет текущую страницу в очередь; соседняя стрелка открывает выбор диапазона;
- очередь продолжает работу при смене страницы, книги и раздела приложения;
- панель внизу справа показывает общий прогресс, этап обработки и счётчики для каждой страницы;
- задачи выполняются последовательно, повторное добавление ожидающей или выполняющейся страницы не создаёт дубликат;
- можно отменить одну задачу или всю очередь; текущий вызов OCR/переводчика завершается, после чего обработка останавливается;
- сохранённые результаты остаются; «Продолжить / повторить ошибки» пропускает уже переведённые области;
- очередь существует до закрытия приложения; сохранённые переводы остаются в SQLite.

Словарь — ручная шпаргалка. Он не передаётся переводчику и не подменяет слова в тексте.

## Локальный переводчик

Перевод выполняет CTranslate2 и SentencePiece. Модель — пакет Argos Translate English→Russian 1.9. Её кладут локально в `python-worker/models/en-ru`, в Git она не входит:

- `model.bin`
- `config.json`
- `shared_vocabulary.json`
- `sentencepiece.model`

Во время перевода модель не скачивается. Каталог можно заменить переменной `LLR_TRANSLATION_MODEL`. В базе такой перевод помечается `ctranslate2:en-ru`.

Поддерживается только английский → русский.

## Python

В development-режиме нужен отдельно установленный Python 3.10, 3.11 или 3.12. Готовые установщики включают собственный Python 3.11.14. Python 3.14 для PaddleOCR не используется. Интерпретатор можно указать через `LLR_PYTHON`. Иначе приложение перебирает `py -3.12`, `py -3.11`, `py -3.10`, `python` и `py -3` и выбирает первый, где есть нужные библиотеки.

Зависимости перечислены в `python-worker/requirements.txt`: `pymupdf`, CPU-сборка `paddlepaddle`, `paddleocr`, `ctranslate2`, `sentencepiece`. Модель перевода в pip не входит. Полная установка — в [SETUP.md](SETUP.md).

## Хранение данных

Каталог данных Tauri. На Windows:

`%APPDATA%\com.locallibrary.reader\`

```
library/documents/   копии PDF
library/trash/       копии, перемещённые в корзину
data/library.db      SQLite
```

В базе хранятся документы, полки, теги, закладки, заметки, области перевода, версии перевода и словари. Сами PDF в базу не записываются. Импорт копирует выбранный файл и не изменяет оригинал. Файл копии удаляется только при окончательном удалении из корзины.

## Development

Проект проверялся на Windows 10. Нужны Node.js и npm, Rust с Cargo, WebView2, компилятор MSVC и Python 3.10–3.12. Версии Node и Rust в репозитории не зафиксированы. Пошаговая установка, модели и переменные окружения описаны в [SETUP.md](SETUP.md).

```bash
npm install
npm run tauri dev
```

Проверки: `npm test` (поиск и очередь), `npm run build`, `cargo test --offline --lib` из `src-tauri`.
Браузерная проверка с тестовым PDF и подменой Tauri: [tests/README.md](tests/README.md).

## Known Limitations

- Читаются только PDF. EPUB, MOBI и комиксы не поддерживаются.
- Поиск и выделение текста используют существующий текстовый слой PDF; OCR-индексации сканов пока нет.
- Очередь перевода не восстанавливается после закрытия приложения. Повторная постановка страниц пропускает сохранённые области.
- Перевод только с английского на русский. OCR настроен на английский.
- Качество OCR зависит от скана: мелкий, кривой или слабо контрастный текст читается плохо.
- Сложная вёрстка, таблицы и несколько колонок могут превратиться в неточные блоки.
- Если на странице есть хотя бы один пригодный блок текстового слоя, остальная страница через OCR не дополняется.
- Словарь не влияет на перевод и не предлагает подсказки на странице.
- Для development нужен Python. Установщики собираются через GitHub Actions и включают собственный runtime; модели загружаются отдельно. Подпись и ограничения macOS описаны в DISTRIBUTION.md.
- Модели OCR и перевода тяжёлые: первый запуск после старта worker занимает заметное время. Повторный вызов в том же процессе модель заново не загружает.
- Повторное добавление страницы в очередь сохраняет существующие переводы и обрабатывает только недостающие области.
