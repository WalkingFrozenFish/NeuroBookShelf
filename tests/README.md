# Проверки читалки

Backend: `python -m unittest discover -s tests -p "test_*.py"` проверяет каталог, установку, отмену, выбор маршрутов и сохранение исходного текста на целевом языке. Эти тесты не скачивают настоящие модели. Для реального inference с уже установленными тестовыми моделями и Lingua запустить `python scripts/smoke_multilingual.py` (скрипт использует приватный Python из `bundle/runtime`). Проверяется смешанный английский/французский/русский текст, смена языка внутри абзаца, перевод через промежуточный язык и сообщение о недостающем пакете. `scripts/smoke_translation_pairs.py` проверяет отдельные направления.

`npm test` запускает проверки локализации, поиска и очереди через встроенный Node test runner.
Используется установленный в проекте TypeScript, новые зависимости не нужны.
Тесты проверяют поиск через границы текстовых элементов, специальные символы,
кириллицу, очередь диапазона, дубликаты, отмену во время перевода, повтор ошибок,
OCR fallback и работу без подписчиков интерфейса.

## Проверка в браузере

Требуется отдельно доступный Playwright и установленный Edge (или другой Chromium).
Playwright нужен только для этого теста, приложение от него не зависит.

1. Запустить `npm run dev`.
2. Если Playwright не установлен рядом с проектом, указать путь к его модулю
   в `LLR_PLAYWRIGHT_MODULE`.
3. Запустить `node tests/reader-ui.mjs`.

Дополнительные переменные: `LLR_TEST_URL` (по умолчанию `http://localhost:1420`),
`LLR_BROWSER_CHANNEL` (по умолчанию `msedge`, можно `chrome`).

Тест проверяет тёмную заливку во время загрузки PDF во всех трёх режимах отображения и быстрые переходы между страницами с искусственно замедленным завершением отрисовки.

Тест создаёт PDF в памяти, включая повёрнутую страницу и оглавление, подменяет
команды Tauri в браузере и хранит результаты в памяти. Пользовательская база,
файлы, модели OCR и перевода не используются. Проверяется настоящее выделение
мышью и копирование в буфер обмена, Ctrl+F, переходы поиска и оглавления,
узкое окно, работа очереди при смене экранов, пропуск сохранённых переводов,
отмена и возобновление. Тест использует буфер обмена тестового браузера.
Снимок результата сохраняется в `tests/reader-ui.png` (исключён из Git).


## Языки, модели и оформление

Браузерный сценарий также проверяет переключение русский → English → русский без перезапуска, сохранение языка и customColor, применение выбранного hue, отмену загрузки модели, повтор и автоматический выбор установленной French → English, смену исходного/целевого языка и поиск по таблице моделей. Команды моделей подменяются тестовыми ответами; пользовательские модели и данные не меняются.

Проверяются четыре вкладки настроек, навигация стрелками/Home, отмена подтверждения сброса без изменения данных, сохранение загрузки при смене вкладки, отсутствие горизонтального переполнения при ширине 900 и 600 px, корзина в боковой панели и обновление книг/счётчиков после восстановления. Дополнительно проверяются переход из пустой читалки в библиотеку, пустой результат поиска без карточки словаря и сброс фильтров библиотеки и моделей. Снимки настроек сохраняются в `tests/settings-*.png` (исключены из Git).

Python unit tests проверяют отмену во время сетевого чтения, отсутствие частично установленной модели, повтор после отмены, выбор одной пары и проверку сохранённого идентификатора.

Настоящий перевод и переключение моделей внутри одного worker проверяются отдельно:

```sh
python scripts/smoke_translation_pairs.py --models-dir /path/to/installed/models
```

С `--download` скрипт сначала скачает и проверит все четыре пары (около 500 МиБ). OCR для этого теста не требуется. Требуется упакованный Python в `bundle/runtime`. Основной CI smoke по-прежнему устанавливает только English → Russian и OCR; он не скачивает необязательные пары при каждой сборке.
