# Проверки читалки

`npm test` запускает проверки поиска и очереди через встроенный Node test runner.
Используется установленный в проекте TypeScript, новые зависимости не нужны.
Тесты проверяют поиск через границы текстовых элементов, специальные символы,
кириллицу, очередь диапазона, дубликаты, отмену во время перевода, повтор ошибок,
OCR fallback и работу без подписчиков интерфейса.

## Проверка в браузере

Требуется отдельно доступный Playwright и установленный Edge (или другой Chromium).
Playwright нужен только для этого теста, приложение от него не зависит.

1. Запустить `npm run dev`.
2. Если Playwright не установлен рядом с проектом, указать путь к его модулю
   в `LLR_PLAYWRIGHT_MODULE`.
3. Запустить `node tests/reader-ui.mjs`.

Дополнительные переменные: `LLR_TEST_URL` (по умолчанию `http://localhost:1420`),
`LLR_BROWSER_CHANNEL` (по умолчанию `msedge`, можно `chrome`).

Тест создаёт PDF в памяти, включая повёрнутую страницу и оглавление, подменяет
команды Tauri в браузере и хранит результаты в памяти. Пользовательская база,
файлы, модели OCR и перевода не используются. Проверяется настоящее выделение
мышью и копирование в буфер обмена, Ctrl+F, переходы поиска и оглавления,
узкое окно, работа очереди при смене экранов, пропуск сохранённых переводов,
отмена и возобновление. Тест использует буфер обмена тестового браузера.
Снимок результата сохраняется в `tests/reader-ui.png` (исключён из Git).
