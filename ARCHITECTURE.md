# Architecture

## Общая схема

React UI
    ↓
Tauri
    ↓
Local services
    ├── SQLite
    ├── filesystem
    └── Python worker
            ├── PyMuPDF
            ├── PaddleOCR
            └── local translator

## Ответственность компонентов

### React

React отвечает только за интерфейс и пользовательское состояние.

React НЕ должен:

- напрямую работать с файловой системой;
- выполнять OCR;
- запускать модели;
- содержать бизнес-логику работы с файлами.

### Tauri

Tauri отвечает за:

- доступ к файловой системе;
- импорт PDF;
- копирование PDF;
- перемещение файлов;
- экспорт файлов;
- работу с SQLite;
- запуск Python worker;
- IPC между UI и локальными сервисами.

### Python worker

Python worker используется только для задач обработки документов.

Задачи:

- рендер области или страницы PDF в памяти;
- определение текстового слоя;
- извлечение текста и координат;
- OCR;
- перевод.

Обмен идёт построчным JSON: команда приходит в stdin, один JSON-ответ уходит в исходный stdout. Сообщения библиотек пишутся в stderr и не смешиваются с протоколом.

Команды приложения: `analyze_page`, `ocr_region`, `ocr_page`, `translate`.

Перевод выполняет локальный класс `Translator` на CTranslate2 и SentencePiece. `model-manifest.json` содержит встроенный резервный каталог и закреплённые SHA-256 проверенных пакетов. Команда `refresh_model_catalog` получает официальный JSON Argos; проверенный список сохраняется в `models/catalog.json`. Кэш и установленные модели доступны без сети. Загрузчик принимает HTTPS-ссылки официальных модельных серверов, проверяет метаданные и извлекает только разрешённые файлы. Для удалённых пакетов без опубликованной контрольной суммы сохраняется локальный SHA-256 скачанного архива; это проверка целостности кэша, а не подпись издателя.

`models/translation-choice.json` хранит `sourceLanguage` (`auto` или код языка) и `targetLanguage`. Старое поле `pair` читается для совместимости. `translation_router.py` определяет языки фрагментов локально через Lingua и выбирает кратчайший установленный путь: прямой перевод или два шага через промежуточный язык. Текст на целевом языке сохраняется без перевода. При неуверенном определении или отсутствии моделей возвращается явная ошибка. Перевод не скачивает модели. В памяти удерживаются не более двух экземпляров переводчика; `last-translation.json` показывает фактически использованные направления. Идентификатор сохранённого перевода — `ctranslate2:en-ru` или `ctranslate2:auto-ru` для нескольких языков.

Очередь фиксирует направление при добавлении задачи и сохраняет его при повторе. Настройки новых задач доступны также из меню перевода в читалке. Существующие переводы не заменяются автоматически. Установка получает конкретную языковую пару; OCR скачивается отдельно (`pair: "ocr"`). Отмена передаётся файлом `cancel-download`, независимо от занятого IPC worker; готовые файлы сохраняются. Загрузчик проверяет сигнал между сетевыми чтениями и распаковкой файлов. OCR пока распознаёт английский; многоязычный перевод других языков использует текстовый слой PDF.

Русские строки интерфейса служат ключами для английского словаря `src/locales/en.json`. `src/i18n.ts` управляет языком и подстановками. Язык интерфейса и `customColor` сохраняются вместе с оформлением в desktop settings и локальном кэше. Цветовая схема получает hue выбранного цвета, а контраст и яркость задаёт CSS для каждого режима.

Не переносить общую бизнес-логику приложения в Python.

## Хранение файлов

Данные приложения лежат в каталоге данных Tauri, а не рядом с исходниками.

На Windows это `%APPDATA%\com.locallibrary.reader\`:

```
library/
    documents/
    trash/
data/
    library.db
```

Документы копируются в `library/documents` под внутренним именем. Исходный файл пользователя не изменяется и не удаляется.

Удаление в корзину переносит копию в `library/trash` и оставляет запись в SQLite. Файл удаляется с диска только командой окончательного удаления.

Миниатюры страниц рисует PDF.js в читалке и на диск не сохраняет. Изображения для OCR остаются в памяти процесса Python. Отдельные каталоги обложек и кэша переводов не используются.

## SQLite

Основные сущности:

- documents
- shelves
- document_shelves
- tags
- document_tags
- bookmarks
- notes
- translation_blocks
- translation_versions
- dictionaries
- dictionary_entries

## Координаты

Координаты областей страницы и popup должны храниться относительно размеров страницы:

0.0 ... 1.0

Не хранить абсолютные экранные пиксели.

Пример:

x = 0.25
y = 0.15
width = 0.40
height = 0.10

## Translation Block

TranslationBlock представляет одну область страницы.

Пример структуры:

- id
- documentId
- pageNumber
- sourceX
- sourceY
- sourceWidth
- sourceHeight
- popupX
- popupY
- popupWidth
- popupHeight
- ocrText
- createdAt
- updatedAt

Текст активной версии дополнительно хранится в колонке `translated_text` той же таблицы. Читалка показывает активную TranslationVersion. Старые версии не перезаписываются.

Переводы хранятся отдельно как версии.

TranslationVersion:

- id
- translationBlockId
- translatedText
- translator
- createdAt
- isActive

## PDF processing

Алгоритм:

1. Открыть PDF.
2. Проверить наличие текстового слоя.
3. Если текстовый слой есть:
   - получить текст;
   - получить координаты.
4. Если текстового слоя нет:
   - отрендерить страницу или выбранную область;
   - выполнить OCR.
5. Передать полученный текст переводчику.
6. Сохранить результат.

Перевод целой страницы собирает общая очередь `src/translationQueue.ts`: она вызывает существующие команды Tauri по этому алгоритму и сохраняет каждый новый блок отдельно. Все задачи последовательные и используют тот же Python worker. Очередь существует независимо от экрана, но не переживает закрытие приложения. Отмена проверяется между операциями, включая проверку после перевода перед сохранением. Повтор пропускает сохранённые области. Отдельного серверного оркестратора нет.

## Ограничения

Не добавлять новый инфраструктурный компонент, если текущий стек уже решает задачу.

Перед добавлением новой зависимости необходимо объяснить её необходимость.
