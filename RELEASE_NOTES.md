# NeuroBookShelf 0.1.0

Локальная PDF-библиотека с поиском по книге, выделением и копированием текста, оглавлением, заметками, закладками и фоновым переводом English → Russian.

## Скачать и установить

- **Windows x64:** скачайте `NeuroBookShelf_0.1.0_x64-setup.exe` и запустите установщик.
- **Windows portable:** скачайте `NeuroBookShelf-0.1.0-windows-x64-portable.zip`, распакуйте в доступную для записи папку и откройте `NeuroBookShelf.exe`. Библиотека и модели сохраняются рядом с приложением в `user-data/`; переносите всю папку целиком.
- **macOS Apple Silicon (M1 и новее):** скачайте `NeuroBookShelf_0.1.0_aarch64.dmg` и перенесите приложение в Applications. Intel Mac пока не поддерживается.

Python и библиотеки уже включены. Git, Node.js, Rust и ручная установка пакетов не нужны. Windows-установщик скачает WebView2, если его нет.

При первом запуске нажмите «Модели», чтобы загрузить около 199 МиБ моделей OCR и перевода. Можно пропустить загрузку и сразу читать PDF. После загрузки моделей OCR и перевод работают локально, без интернета.

## Подпись приложения

Windows-сборка пока без сертификата издателя, поэтому SmartScreen может показывать предупреждение. macOS-сборка имеет тестовую ad-hoc подпись и не нотарифицирована Apple; Gatekeeper может блокировать запуск. Поддержка Developer ID и нотарификации подготовлена, но требует сертификата владельца проекта.

## Проверки

Установщики собраны на Windows и macOS. Автоматические проверки включают загрузку моделей с SHA-256, реальное OCR и перевод, чтение PDF и запуск Python из упакованного приложения. Для macOS также проверяется целостность подписи. Файлы `SHA256SUMS-*.txt` содержат контрольные суммы загрузок.
